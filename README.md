# Perso Music

Página pública de Perso Music, el reproductor personal para iPhone y Android.

Se publica con GitHub Pages en https://xous3r.github.io/persomusic/ e incluye los créditos de los servicios que usa la app: el ritmo (BPM) de [GetSongBPM.com](https://getsongbpm.com) y las letras sincronizadas de [LRCLIB](https://lrclib.net).

Es una sola página (`index.html`) sin dependencias ni proceso de compilación.
